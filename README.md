# DyslexAI

> An RTL-Aware Multimodal Webcam-Based Early Dyslexia Screening System for Urdu Readers.

## Project

DyslexAI is a webcam-based multimodal dyslexia screening system focused on Urdu readers. The system combines eye-tracking, speech analysis, and behavioural screening into a unified platform.
